# ROYAL TV V16 / V17 icon assets

These are original static SVG variants from ROYAL DESIGN GALLERY:
- V16 TV icons: television source, channels, cast, remote, live, settings, fullscreen, volume and status actions.
- V17 launcher icons: apps, music, movies, favorites, guide and live TV.
- V17 music player icons: play/pause, previous/next, shuffle, repeat, queue, search, lyrics, volume and related actions.
- V17 video player icons: play/pause, seek, previous/next, fullscreen, subtitles, mute, volume and library actions.

The original animated SVGs use SMIL. The app renders the original static SVG artwork through AndroidSVG and adds lightweight Compose motion based on focus/playback state. No SMIL runtime dependency is required.

All assets are bundled locally; there are no runtime network requests for icons. The ROYAL TV minimum SDK remains 23.
